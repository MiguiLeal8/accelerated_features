# Overview and Repository Structure: XFeat (CVPR 2024)

This document serves as a technical guide and summary of the architecture, scripts, and modules of the official repository for **XFeat: Accelerated Features for Lightweight Image Matching**.

---

## 1. Project Overview

XFeat is a lightweight convolutional neural network designed for real-time local feature extraction (keypoints and 64-dimensional descriptors) and visual matching inference. It supports two main operating modes:
- **Sparse Mode:** Fast, pixel-level keypoint extraction and 64D descriptor generation.
- **Semi-Dense Mode:** Feature matching with sub-pixel refinement for maximum precision.

---

## 2. Repository Structure

```text
.
├── assets/                  # Sample images and benchmark metadata (e.g., megadepth_1500.json)
├── figs/                    # Architecture diagrams, speed/accuracy plots, and demo GIFs
├── notebooks/               # Interactive Jupyter notebooks for testing, inference, and training
├── third_party/             # Third-party baseline methods (e.g., ALIKE) and their wrappers
├── weights/                 # Pre-trained weights (.pt) for XFeat and LighterGlue
├── modules/                 # Core source code: model architecture, loss functions, datasets, and evaluation
│   ├── dataset/             # Dataloaders and augmentation pipelines (MegaDepth and COCO)
│   ├── eval/                # Benchmarking scripts for pose estimation
│   ├── training/            # Loss functions and training pipeline (train.py)
│   ├── interpolator.py      # Bilinear/nearest interpolation module for feature maps
│   ├── lighterglue.py       # Adapted/lightweight version of LightGlue for XFeat
│   ├── model.py             # Main network architecture (CNN with space-to-depth decoupling)
│   └── xfeat.py             # High-level wrapper interface (match_xfeat, detectAndCompute)
├── general_inference.py     # Custom script for local inference testing on single or paired images
├── hubconf.py               # Official PyTorch Hub integration script
├── minimal_example.py       # Minimal runnable script via command line
├── realtime_demo.py         # Real-time visual matching demo using a webcam or video stream
└── requirements.txt         # Project dependencies
```

## 3. Detailed File and Module Descriptions

### 3.1 `assets/` Directory

The `assets/` directory contains sample inputs for testing and ground-truth metadata used in benchmark evaluations.

* **`ref.png` & `tgt.png`**: Sample reference and target image pair used by default in `general_inference.py`, `minimal_example.py`, and demo notebooks for quick feature extraction and matching tests.
* **`megadepth_1500.json`**: An evaluation dataset metadata file containing 1,500 image pairs from the MegaDepth benchmark. Each entry defines ground-truth geometric parameters required for relative pose estimation evaluation:
  * **`T_0to1` / `T_1to0`**: $4 \times 4$ rigid transformation matrices (rotation and translation) mapping coordinates between camera spaces.
  * **`K0` / `K1`**: $3 \times 3$ intrinsic camera calibration matrices.
  * **`scale0` / `scale1`**: Rescaling factors applied during image preprocessing.
  * **`pair_names`**: Original relative file paths of the image pairs in the MegaDepth dataset.
  * **`size0_hw` / `size1_hw`**: Image resolution dimensions (height, width).

### 3.2 `figs/` Directory

The `figs/` directory contains visual assets, diagrams, performance plots, and demonstration GIFs used in the repository's `README.md` and project documentation to illustrate XFeat's architecture and performance.

* **`xfeat_arq.png`**: Architectural diagram illustrating the XFeat neural network design, including the local feature extractor (CNN with space-to-depth modules), keypoint heatmap head, local descriptor head, and the optional semi-dense match refinement module.
* **`speed_accuracy.png`**: Performance trade-off chart comparing XFeat against baseline feature extractors and matchers (e.g., SIFT, ORB, SuperPoint, LoFTR) in terms of accuracy (AUC) versus latency/FPS.
* **`timings.png`**: Detailed latency breakdown showing execution times across hardware platforms (CPU vs. GPU) and individual pipeline stages (feature extraction vs. matching).
* **`xfeat_quali.jpg`**: Qualitative matching results displaying feature correspondances generated by XFeat across challenging image pairs featuring extreme viewpoint changes and varying lighting conditions.
* **`xfeat.gif`**: Animated demonstration showcasing real-time local feature extraction and matching operating at high FPS.
* **`sift.gif`**: Comparative animation illustrating classic SIFT feature extraction performance under similar test conditions.
* **`verlab.png` & `ufmg.png`**: Institutional logos for VeRLab (Computer Vision and Robotics Lab) and UFMG (Universidade Federal de Minas Gerais), the originating research institutions.

### 3.3 `notebooks/` Directory

The `notebooks/` directory provides interactive Jupyter notebooks demonstrating XFeat's feature extraction, image matching, PyTorch Hub integration, and model training workflows.

* **`minimal_example.ipynb`**: A quick-start notebook showcasing basic XFeat inference on synthetic CPU/GPU tensors. Demonstrates keypoint detection and 64D descriptor extraction via `detectAndCompute()`, batched feature extraction, Mutual Nearest Neighbor (MNN) sparse matching via `match_xfeat()`, and semi-dense batched match refinement using `match_xfeat_star()`.
* **`xfeat_matching.ipynb`**: Demonstrates pair-wise image matching using pre-trained XFeat weights. It covers loading image pairs, computing sparse and semi-dense correspondences, fitting homographies via RANSAC/MAGSAC, and visualizing keypoint matches with warped bounding boxes.
* **`xfeat_torch_hub.ipynb`**: Demonstrates how to seamlessly load pre-trained XFeat models directly from the remote GitHub repository using `torch.hub.load()`. Shows feature extraction and basic MNN matching without requiring a local repository clone.
* **`XFeat_training_example.ipynb`**: An end-to-end tutorial notebook walking through the training setup for XFeat. It details synthetic/real dataset preparation, feature loss function configurations (keypoint heatmap loss and descriptor matching loss), and executing a mini-training loop using `modules/training/train.py`.
* **`xfeat+lg_torch_hub.ipynb`**: Illustrates deep feature matching by combining XFeat feature extraction with LighterGlue (a lightened LightGlue architecture) loaded via PyTorch Hub. It highlights the full pipeline: extracting XFeat keypoints/descriptors and passing them into LighterGlue for attention-based match filtering and homography visualization.

### 3.4 `third_party/` Directory

The `third_party/` directory contains external dependencies and baseline model implementations used for benchmark comparisons or integration within the repository.

* **`third_party/ALIKE/`**: A complete local copy of the [ALIKE](https://github.com/Shiaomeng/ALIKE) repository (Accurate and Lightweight Keypoint Detection and Descriptor Extraction).
  * **`alike.py` & `alnet.py`**: Core network architecture and interface definitions for ALIKE feature extraction.
  * **`soft_detect.py`**: Differentiable keypoint detection module implementing sub-pixel keypoint extraction.
  * **`models/`**: Pre-trained model weights (`.pth`) for different model variants (`alike-t`, `alike-s`, `alike-n`, `alike-l`).
  * **`hseq/`**: Benchmark evaluation scripts (`eval.py`, `extract.py`) and cached feature outputs (`.npy`) for evaluation on the HPatches sequence dataset.
  * **`assets/` & `matlab/`**: Sample datasets (KITTI, TUM), visualization demos (`demo.py`, `.gif` previews), and auxiliary plotting scripts.
* **`alike_wrapper.py`**: A bridge module providing a standardized PyTorch/Python API wrapper around ALIKE to integrate its feature detection and extraction into the host project's pipelines.
* **`__init__.py`**: Exposes the third-party integrations as an importable package.

### 3.5 `weights/` Directory

The `weights/` directory stores the pre-trained PyTorch model checkpoint files (`.pt`) containing the learned parameters required for local feature extraction and attention-based match filtering.

* **`xfeat.pt`**: The official pre-trained weights for the primary XFeat architecture. This model contains parameters for the lightweight feature extraction backbone, keypoint detection head, 64-dimensional descriptor head, and the semi-dense match refinement module. It is used by default across inference scripts (`general_inference.py`, `minimal_example.py`) and high-level interface wrappers (`XFeat`).
* **`xfeat-lighterglue.pt`**: Pre-trained weights for the **LighterGlue** matcher adapted specifically to process XFeat keypoints and 64D descriptors. It provides learned graph-neural-network parameters (self- and cross-attention units) optimized for filtering and refining sparse keypoint matches generated by XFeat.

### 3.6 `modules/` Directory (Core Source Code)

The `modules/` directory houses the core model architecture, spatial interpolation utilities, refinement model integrations, and the primary inference interface for XFeat.

* **`__init__.py`**: Module initialization file containing the repository's official header and citation reference to the CVPR 2024 paper.
* **`interpolator.py`**: Defines the `InterpolateSparse2d` class, a PyTorch module designed to efficiently interpolate dense feature tensors `[B, C, H, W]` at discrete 2D sparse positions `[B, N, 2]`. Supports modes like `bicubic` or `bilinear` by normalizing grid coordinates to `[-1, 1]`.
* **`lighterglue.py`**: Implements `LighterGlue`, an optimized and lightweight variant of LightGlue adapted specifically to process XFeat's 64-dimensional descriptors and keypoints. It configures the network to use 6 layers with FlashAttention and automatically loads its pre-trained weights.
* **`model.py`**: Defines the primary convolutional neural network architecture (`XFeatModel`):
  * **CNN Backbone:** Features convolutional blocks (`BasicLayer`), skip connections, and space-to-depth decoupling (`_unfold2d`).
  * **Pyramid Fusion:** Integrates multi-scale feature maps across different resolution levels.
  * **Output Heads:** Includes the `heatmap_head` for visual reliability maps and the `keypoint_head` for keypoint detection at $H/8 \times W/8$ resolution.
  * **Fine Matcher:** A multi-layer perceptron (MLP) head designed for sub-pixel semi-dense match refinement.
* **`xfeat.py`**: The main high-level interface (`XFeat`) wrapping `XFeatModel` to handle all inference workflows:
  * **`detectAndCompute()`**: Extracts sparse keypoints and $L_2$-normalized descriptors via Non-Maximum Suppression (NMS) and bilinear/bicubic interpolation.
  * **`detectAndComputeDense()` / `extract_dualscale()`**: Extracts dense and multi-scale feature representations.
  * **`match_xfeat()` / `match_xfeat_star()`**: Performs matching via standard Mutual Nearest Neighbors (MNN) or sub-pixel semi-dense refinement.
  * **`match_lighterglue()`**: Integrates attention-based match filtering using `LighterGlue`.

### 3.6.1 `modules/dataset/` Directory

The `modules/dataset/` subpackage manages training data generation, dataset acquisition, visual and geometric transformations, and 3D depth-based reprojection utilities for XFeat.

* **`augmentation.py`**: Implements the `AugmentationPipe` class using Kornia to generate synthetic training image pairs from unlabeled images. Applies geometric transformations—such as random homographies and Thin Plate Spline (TPS) non-rigid deformations—alongside photometric augmentations (e.g., color jitter, Gaussian noise, and synthetic shadows). It also provides correspondence mapping (`get_correspondences`) across transformed coordinates.
* **`download.py`**: A command-line downloader script for fetching required training and evaluation datasets—including MegaDepth, MegaDepth-1500, and ScanNet-1500—using `gdown` and `wget`.
* **`__init__.py`**: Initialization module marking the folder as a Python package.

#### `modules/dataset/megadepth/` Subdirectory

Contains the MegaDepth dataset loader and geometric warping utilities for training with real-world 3D scene data.

* **`megadepth.py`**: Implements `MegaDepthDataset`, a PyTorch `Dataset` wrapper that parses scene information files (`.npz`). It loads image pairs, depth maps (`.h5`), intrinsic camera matrices ($K_0, K_1$), and relative camera poses ($T_{0 \to 1}, T_{1 \to 0}$), filtering pairs based on overlap scores.
* **`megadepth_warper.py`**: Provides geometric warping functions to establish pixel correspondences:
  * **`warp_kpts()`**: Unprojects 2D keypoints into 3D camera space using depth maps and intrinsics, transforms them using relative poses, and re-projects them back into the target image plane.
  * **`spvs_coarse()`**: Generates bi-directionally verified ground-truth correspondences across feature grids, removing duplicate keypoint mappings for training supervision.
* **`utils.py`**: Supplies IO and image pre-processing helpers, such as grayscale image reading (`read_megadepth_gray`), depth map parsing (`read_megadepth_depth`), path corrections (`fix_path_from_d2net`), and padding routines (`pad_bottom_right`).

### 3.6.2 `modules/eval/` Directory

The `modules/eval/` subpackage contains benchmark evaluation scripts used to test local feature matchers—such as XFeat, XFeat*, and ALIKE—on standard public datasets. It measures relative camera pose estimation accuracy and Area Under the Curve (AUC) metrics using fast solver libraries.

* **`__init__.py`**: Module initialization file that marks `eval` as a Python package.
* **`megadepth1500.py`**: Benchmarking suite for the outdoor **MegaDepth-1500** dataset.
* **`scannet1500.py`**: Benchmarking suite for the indoor **ScanNet-1500** dataset.

### 3.6.6 `modules/training/` Directory

Contains loss functions, training pipelines, and logging utilities for training XFeat.

* **`__init__.py`**: Package initialization file.
* **`losses.py`**: Comprehensive set of loss functions for coarse matching, fine-level matching, and keypoint detection distillation:
  * **`dual_softmax_loss`**: Computes symmetric cross-entropy loss over coarse feature matching matrices.
  * **`fine_loss`**: Refines match coordinates using sub-pixel patch crops and transformer-based offset prediction.
  * **`alike_distill_loss`**: Knowledge distillation loss using keypoints extracted from the ALIKE model to guide heatmap prediction.
  * **`keypoint_position_loss` & `coordinate_classification_loss`**: Converts continuous spatial coordinates into grid-cell classification labels for precise localization.
  * **`keypoint_loss`**: L1 supervision for heatmaps based on match reliability confidence.
  * **`hard_triplet_loss`**: Metric learning loss with hard negative mining for descriptor embeddings.
* **`train.py`**: Primary entry point for model training:
  * Initializes the `Trainer` class, model instances, Adam optimizer, and `StepLR` scheduler.
  * Supports dynamic training schemes combining real MegaDepth image pairs and self-supervised synthetic image warps.
  * Tracks performance metrics (coarse accuracy, fine coordinate accuracy, loss components) and logs them to TensorBoard.
  * Handles periodic checkpoint saving (`.pth`) and learning rate updates.
* **`utils.py`**: Utility functions for dataset processing and accuracy evaluation during training:
  * **`make_batch`**: Samples batches from the synthetic augmentation pipeline.
  * **`get_corresponding_pts`**: Computes ground-truth point correspondences after applying homography and thin-plate spline (TPS) warps.
  * **`crop_patches`**: Crops localized spatial patches surrounding keypoints for fine-matching modules.
  * **`subpix_softmax2d`**: Computes 2D sub-pixel coordinate offsets using spatial softmax.
  * **`check_accuracy`**: Calculates nearest-neighbor match accuracy across feature embeddings.
